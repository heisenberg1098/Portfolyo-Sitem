#🚀 Kişisel Portföy Sitem
Kişisel portföy sitemin kaynak kodlarına hoş geldiniz! Burası; becerilerimi, projelerimi ve kişiliğimi; göz alıcı 3D animasyonlar, akıcı etkileşimler ve pürüzsüz geçişlerle sergilediğim yer. Eğer yaratıcı web tasarımıyla ilgileniyorsanız, doğru yerdesiniz.

![Portfolio Preview]

🔥 Öne Çıkan Özellikler
3D Animasyonlar: Spline kullanarak tasarladığım interaktif klavye. Tuş başlıkları becerilerimi temsil ediyor; üzerlerine gelindiğinde başlık ve açıklamaları gösteriyor.

Akıcı Etkileşimler: Kaydırma, üzerine gelme (hover) ve elementlerin ortaya çıkma animasyonları için GSAP ve Framer Motion gücünü kullandım.

Uzay Teması: Derin uzay hissi veren karanlık bir arka plan ve parçacık (particle) efektleriyle, "dünya dışı" bir kullanıcı deneyimi.

Duyarlı (Responsive) Tasarım: Tüm cihazlarda en iyi kullanıcı deneyimini sağlamak için tam uyumlu yapı.

Yenilikçi Web Tasarımı: Modern web tasarımının sınırlarını zorlamak için yaratıcılık ve işlevselliği bir araya getirdim.

🛠️ Teknoloji Yığını
Frontend: Next.js, React, Tailwind CSS, Shadcn, Aceternity UI

Animasyon: GSAP, Framer Motion, Spline Runtime

Diğer: Resend, Socket.io, Zod

🚀 Başlangıç
Gereksinimler
Node.js (v14 ve üzeri)

npm veya yarn

Kurulum

1. Depoyu (repository) klonlayın::

    ```bash
    git clone https://github.com/heisenberg1098/Blog-Sitem
    ```

2. Proje dizinine gidin:

    ```bash
    cd Portfolio
    ```

3. Bağımlılıkları yükleyin:

    ```bash
    npm install
    # or
    yarn install
    ```

4. Geliştirme sunucusunu başlatın:

    ```bash
    npm run dev
    # or
    yarn dev
    ```

5. Açın [http://localhost:3000](http://localhost:3000) Sihir gibiii
